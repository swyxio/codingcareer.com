> [!IMPORTANT]
> This repository is an archived record of the original 2020 website and storefront.
> **The complete book is now free to read at [learninpublic.org](https://learninpublic.org/).**
> The current open-source book, build system, and contribution history live at
> [forge.smol.ai/swyx/codingcareer](https://forge.smol.ai/swyx/codingcareer).

## What changed in 2026

On August 18, 2026, *The Coding Career Handbook* was released as a free,
open-web edition. The book was rebuilt from a reviewed manuscript snapshot in a
fresh Git history using Quarto. One source now produces the website, EPUB, and
PDF editions.

The old checkout, payment integrations, analytics, account flows, and legacy
Sapper application were retired rather than carried forward. The new edition
has no checkout, account, or tracking requirement.

This repository remains available for historical context. Its Git history was
deliberately not merged into the new source repository, which keeps the current
publication history focused on the reviewed book source and avoids carrying
obsolete application and commerce code.
